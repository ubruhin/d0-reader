# nuoreader firmware

## Toolchain

The
[ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/v5.2.2/esp32c6/get-started/index.html)
toolchain **v5.2.2** is required to build the firmware.

## Build

    idf.py build

## Flash

    idf.py flash

## Flash & Run/Monitor Application

    idf.py flash monitor
